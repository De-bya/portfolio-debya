# Debya Ahmed Salem — Portfolio

Personal portfolio website, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/).

🔗 Live at: https://De-bya.github.io/portfolio-debya/

## Pages

- **Home** — intro and social links
- **About** — bio, skills, and languages
- **Education** — academic background
- **Career** — work experiences
- **Projects** — Personal and Academic Projects
- **Certificates** — certifications by year
